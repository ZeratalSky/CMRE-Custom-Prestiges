# Lost的网络管理员：来源与实现说明

## 必要依赖

- `CMRE_Core_Base.SC2Mod`：复用菲尼克斯V2的战术数据网数值、单位属性修正、伤害响应和保护者防护场数据。
- `CMRE_Core_Triggers.SC2Mod`：复用智能人格、普通备用躯壳分组以及人格转换事件。

## 设计与实现

- 设计来源：用户提供的“菲鸡V2修改版”方案。
- 人格复活不会创建免费单位：阵亡时记录全部当时已经存在的对应普通躯壳；只有其中一个躯壳实际完成人格转换时，才把新人格移动到阵亡地点。
- 阵亡时没有备用躯壳，或者当时存在的躯壳全在转换前阵亡时，后续新躯壳沿用原版机制，在自身位置接管人格。
- 35%折扣以原版菲尼克斯V2的50%折扣数据为基准按70%换算，保留原版V2的生命、护盾和伤害惩罚。
