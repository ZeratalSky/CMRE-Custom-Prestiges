# CMRE 自制威望合集

这是一个用于《星际争霸 II》CMRE 的模块化自制威望扩展，包含多个自制威望。以后新增的威望也会放在同一个 `prestiges` 目录中。
部分创意来源自网络
## 安装

1. 从 [CMRE 核心仓库](https://github.com/WondersReady/CMRE_OpenSource) 下载 ZIP。
2. 解压后，把 CMRE 的 `Mods` 和 `Maps` 复制到《星际争霸 II》根目录。
3. 下载本仓库 ZIP，把解压得到的整个文件夹放进游戏的 `Mods` 文件夹。
4. 登录战网客户端，保持游戏未启动。
5. 如需选择威望，双击 `选择安装的威望.bat`，勾选后点击“保存并同步”。
6. 双击本仓库中的 `安装并启动CMRE.bat`。

目录关系应类似：

```text
D:\StarCraft II
├─ Maps
│  └─ CMRE
└─ Mods
   ├─ CMRE
   └─ CMRE-Custom-Prestiges-main
      ├─ 选择安装的威望.bat
      └─ 安装并启动CMRE.bat
```

普通安装不需要打开 PowerShell，也不需要手工填写游戏路径。更详细的步骤见 [完整安装教程](docs/INSTALLATION.md)。

## 首次运行

本地任务会用到 CMRE 在战网发布的整合包、因子包、官方威望包和美术资源。首次运行时，启动器会从本机已有的 Battle.net 缓存中查找这些文件；缓存不完整时会打开星际争霸 II 编辑器取得依赖。编辑器完成加载后将其关闭，安装窗口便会继续。

如果仍有缺少项，可以先从战网大厅完整进入一次 CMRE，等下载结束后退出游戏，再运行 `首次准备CMRE依赖.bat`。

仓库不会附带或上传这些战网资源。它们始终来自玩家自己的游戏缓存。

## 使用

`安装并启动CMRE.bat` 会同步已经选择的威望、准备本地任务所需的依赖，然后打开 `Maps\CMRE\Launcher.SC2Map`。进入启动器后可以选择指挥官、威望、突变因子、难度和任务地图。

另外几个入口分别用于：

- `选择安装的威望.bat`：按指挥官筛选威望，勾选需要安装的内容并自动同步。
- `安装自制威望.bat`：只同步威望，不启动游戏。
- `首次准备CMRE依赖.bat`：只准备本地依赖。
- `卸载自制威望.bat`：卸载本工具安装的全部自制威望。

选择结果保存在 `Mods\CMRE\CMRE_自制威望选择.txt`，当前安装记录保存在 `Mods\CMRE\CMRE_自制威望安装记录.txt`。没有创建选择文件时，默认安装 `prestiges` 中的全部威望。

## 当前威望

### 雷诺：全能游骑兵

**优点**

- 同时获得雷诺三个原版威望的正面效果，保留矿骡、机械单位折扣和原版单位价格。
- 休伯利安号保留首次 300 秒、使用后 360 秒的原版冷却，召唤后立即开始计时。
- 休伯利安号没有持续时间限制，每秒恢复 6 点生命值；场上已有一艘时不能重复召唤。
- 高级定点防御无人机每 60 秒恢复 1 次使用次数，最多储存 9999 次。

**缺点**

- 无。

### 阿塔尼斯：全能大主教

**优点**

- 同时获得阿塔尼斯三个原版威望的正面效果。
- 战斗单位的主动技能获得强化，但单位价格保持不变。
- 投射能量场可以转移已有能量场内的部队，冷却时间为 1 秒，并且不额外消耗能量。
- 轨道轰炸会折跃无拘狂热者；护盾超载保留原版全军生效方式，并获得第三威望的能量与冷却强化。
- 守护之壳的冷却时间为 60 秒。
- 游戏时间达到 4 分钟时，英雄阿塔尼斯加入战斗。他拥有 500 点生命值和 500 点护盾，不受普通攻防升级影响，阵亡后 60 秒复活。
- 英雄拥有闪电冲锋和星界之风。星界之风冷却时间为 5 秒，为自己和附近友军恢复 100 点生命值与 50 点护盾。

**缺点**

- 无。

### 阿塔尼斯：牢鸦的拥抱战斗的荣耀

**优点**

- 轨道轰炸无冷却，每发携带一名永久存在的无拘狂热者；无拘狂热者的护盾与护盾恢复速度提高 100%。
- 守护之壳冷却时间减少 50%。
- 每损失 2 人口获得 1 点亚顿之矛能量。

**缺点**

- 光影议会、圣堂武士文献馆、机械研究所、舰队航标和护盾超载不可用。
- 守护之壳只对无拘狂热者和队友生效；亚顿之矛能量不再自动恢复，攻防升级不可用。
- 轨道轰炸能量消耗提高 100%，且不再对地面造成伤害。
- 机械台与星门单位造价提高 50%，观察者除外。

### 斯台特曼：超级信号专家

**优点**

- 艾星无敌，视野扩大 50%，艾场范围扩大 50%，并且可以探测隐形单位。
- 三种艾场会对敌方单位施加对应的减速、减甲与 10% 易伤，或能量流失效果。
- 艾星超载时会自动对敌方单位施放持续 45 秒的对应超载：移动与攻击速度降低 99%、护甲降至 0 并获得 25% 易伤，或清空全部能量。

**缺点**

- 超级盖瑞不可用。

### 菲尼克斯：Lost的网络管理员

**优点**

- 战术数据网的效果提高 200%，普通作战单位的资源消耗降低 35%。
- 智能人格阵亡时，如果当时已有对应普通备用躯壳，会消耗其中一个躯壳并在阵亡地点复活。
- 如果阵亡时没有备用躯壳，之后补充的对应躯壳仍在自身位置接管人格。
- 保护者的防护场可以在全地图范围内施放。

**缺点**

- 非英雄作战单位的生命值、护盾值和造成的伤害降低 50%。
- 防护场冷却时间延长至 40 秒。

### 雷诺：死水军阀

- 生物战斗单位生命值提高 100%，所有可训练作战单位替换为对应的战役佣兵。
- 矿骡不可用。

### 雷诺：雇佣兵指挥官

- 所有可训练作战单位替换为对应的战役佣兵。
- 无额外劣势。

### 雷诺：雇佣兵游骑兵

- 星港无需瓦斯，空军瓦斯消耗降低 30%，并根据空军人口加快面板技能冷却。
- 所有可训练作战单位替换为对应的战役佣兵。
- 作战单位矿物消耗提高 50%。

以上三个佣兵替换威望共用同一套单位数据和单位替换触发器，可以同时安装。每名玩家只会按照自己当前选择的威望启用对应效果，因此双人游戏中也可以分别选择不同的佣兵雷诺威望。

## 更新与卸载

更新 CMRE 或本仓库后，再运行一次 `安装并启动CMRE.bat`。安装器会在修改前备份相关数据，并让已安装内容与 `prestiges` 目录保持一致。

停用单个威望时，把对应目录移出 `prestiges`，再运行 `安装自制威望.bat`。要移除本工具安装的全部威望，双击 `卸载自制威望.bat`。从战网缓存准备的依赖会保留，以免影响其他本地 CM/CMRE 地图。

## 添加威望

每个威望都有独立目录和 `prestige.json`。安装器会自动发现新模块，没有在脚本中写死数量。目录格式和模板见 [添加新威望](docs/ADDING_PRESTIGES.md)。

## 兼容性

本项目依赖 CMRE，不能单独运行。CMRE 或战网依赖更新后，目录结构和缓存版本可能发生变化；遇到依赖不匹配时，请先更新 CMRE 和本仓库，再重新准备依赖。
